# Talking to them through Dream

Everything they see from you reaches them through `dream`: messages and email, questions, the Status card,
workstreams and a Live Activity. It works from any process in this sandbox, including the apps you build. This
skill says what each one shows them and when it's worth using; `dream <command> --help` lists every flag, with
examples.
