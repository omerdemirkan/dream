# Reaching them, and the agent

`dream` reaches Dream from here, as it does for the agent; the skill describes it. Send the person something only
when the brief says to, since what they hear about the project is the agent's to decide. When the job can't be done,
its result would be wrong, or it needs a decision the brief doesn't settle, `dream wake "<what happened and what's
needed>"` wakes the agent with your words, and it takes it from there. A run that fails outright wakes it too: an
error, running out of time after half an hour, or the person's usage limit.
