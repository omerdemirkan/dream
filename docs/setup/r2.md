# Enable R2 (media storage)

**Why:** agents attach screenshots and screen recordings to Chat messages, and the Status card shows media. Until R2
is on, `dream message --media` answers "Media storage isn't switched on for this deployment yet", so you only ever
get text.

**Steps**

1. Cloudflare dashboard (account `2d98de7c4511e98d2f774c4fcc9b9b93`) → **R2 Object Storage** in the sidebar.
2. Click **Enable R2** / **Purchase R2 Plan**. It asks for a payment method; the free tier (10 GB stored, 1M writes,
   10M reads a month) covers Dream's use for a long time. You don't need to create a bucket.
3. Tell me it's on.

**What I do then:** set `DREAM_R2_ENABLED=true` in the root `.env`, run `bun run infra:deploy` from `main` (it creates
the `dream-media` bucket and binds it), and check an upload end to end from a sandbox.

If you'd rather do it yourself: same two steps, from the repo root on an up-to-date `main`.
